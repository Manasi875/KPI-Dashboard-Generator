# Metricly — KPI Dashboard Generator

A polished React + Vite analytics dashboard that turns business metrics and CSV datasets into an interactive KPI workspace.

## Highlights

- Responsive analytics dashboard
- KPI creation, editing, filtering and deletion
- CSV import with automatic KPI detection
- Dataset preview table
- Performance, growth and health summaries
- Interactive trend, attainment and distribution charts
- Smart insights and recent activity panels
- Responsive sidebar/navigation
- Light/dark theme toggle
- Modern SaaS-style UI

## Tech Stack

- React 19
- Vite
- Chart.js + react-chartjs-2
- Lucide React
- PapaParse

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```
